## اهداف یادگیری
پس از این ماژول می‌توانید:
1. ساختار FASTA، FASTQ، GFF3، GenBank، BED، SAM/BAM و VCF را بخوانید و تفسیر کنید.
2. مختصات مبنای ۰ (BED) و مبنای ۱ (GFF، SAM، VCF) را بدون خطای off-by-one تبدیل کنید.
3. با ایندکس‌ها (`.fai`، `.bai`، `.tbi`) به نواحی دسترسی تصادفی داشته باشید.
4. یک فایل VCF را با «حقیقت» مقایسه کنید و نقش عمق پوشش را بفهمید.

## پیوند با ماژول‌های دیگر
فایل‌های نمونه از داده‌ی واقعی ماژول‌های قبلی ساخته می‌شوند: ژنوم *E. coli* (01/01)، FASTQ (03/01)، و BAM حذف میزبان (03/02). VCF از جهش‌هایی ساخته می‌شود که `wgsim` در ریدهای انسانی شبیه‌سازی‌شده گذاشته است، پس «حقیقت» برای مقایسه موجود است.
