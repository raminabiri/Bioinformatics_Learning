# درس ۲: پرسیدن از فایل‌ها با grep، cut، sort، uniq و awk

**بخش:** `01_Computing_Foundations` · **ماژول:** `01_Bash_Linux` · **پیش‌نیاز:** [درس ۱](01_lesson_files.md) · **زمان:** حدود ۶۰ دقیقه · **ابزار:** grep، cut، sort، uniq، awk، sed (GNU) · **آخرین اجرا:** 2026-10-19

## در یک نگاه

**در پایان این درس می‌توانید:**
1. ستون‌های یک فایل GFF را بشناسید.
2. با `grep` خط‌های دلخواه را پیدا کنید و بشمارید.
3. با الگوی `cut | sort | uniq -c` بشمارید «از هر چیز چندتا داریم».
4. با `awk` روی ستون‌ها شرط بگذارید و حساب کنید (شمار، جمع، میانگین).
5. با `awk` ریدهای یک FASTQ را بشمارید و میانگین طولشان را بگیرید.

همه‌ی دستورها را در پوشه‌ی `01_Computing_Foundations/01_Bash_Linux/data` اجرا کنید.

## ۱. داستان: از فهرست ژن‌ها بپرسیم

فایل `ecoli_k12.gff` فهرست همه‌ی ژن‌ها و چیزهای دیگری است که روی ژنوم *E. coli* K-12 شناخته شده. پرسش‌های ما:
- ژنوم چند ژن دارد؟
- چند ژن روی رشته‌ی مثبت و چند تا روی رشته‌ی منفی است؟
- ژن‌های RNA پلیمراز (نامشان با `rpo` آغاز می‌شود) کدام‌اند؟
- میانگین طول ژن‌ها چقدر است؟

پیش از پاسخ، باید بدانیم این فایل چه شکلی دارد.

---

## ۲. فایل GFF: یک جدول با ۹ ستون

GFF یک **جدول متنی** است. هر خط یک «چیز» روی ژنوم است (یک ژن، یک CDS، یک tRNA…) و ستون‌ها با **Tab** از هم جدا شده‌اند. خط‌هایی که با `#` آغاز می‌شوند، توضیح‌اند و داده نیستند.

برای اینکه با چشم دنبال کنیم، نخست یک فایل کوچک ۸ خطی می‌سازیم:

<div dir="ltr">

```bash
grep -v '^#' ecoli_k12.gff | head -n 8 > small.gff
```

</div>

(`grep -v '^#'` یعنی خط‌هایی که با `#` آغاز **نمی‌شوند**. در بخش ۴ دقیق‌تر می‌بینیم.)

این ستون‌های خط دوم `small.gff` است، که ژن *thrL* را توصیف می‌کند:

| ستون | نام | مقدار | یعنی |
| :-: | :--- | :--- | :--- |
| 1 | seqid | `NC_000913.3` | روی کدام توالی (کروموزوم) |
| 2 | source | `RefSeq` | چه کسی یا چه برنامه‌ای این را یافته |
| 3 | type | `gene` | چه نوع چیزی (gene، CDS، tRNA…) |
| 4 | start | `190` | جای آغاز |
| 5 | end | `255` | جای پایان |
| 6 | score | `.` | امتیاز (`.` یعنی ندارد) |
| 7 | strand | `+` | روی کدام رشته |
| 8 | phase | `.` | برای CDS؛ این‌جا کاربرد ندارد |
| 9 | attributes | `ID=gene-b0001;…;Name=thrL;…` | آگاهی‌های دیگر، به شکل `نام=مقدار` با `;` جدا شده |

**طول ژن:** شماره‌گذاری در GFF از ۱ است و هر دو سر جزو ژن‌اند، پس طول = پایان − آغاز + ۱. برای *thrL*: ۲۵۵ − ۱۹۰ + ۱ = **۶۶ نوکلئوتید**.

## ۳. `cut`: برداشتن ستون‌ها

`cut -f` ستون‌هایی را که می‌خواهید جدا می‌کند. جداکننده‌ی پیش‌فرض آن Tab است، درست همان جداکننده‌ی GFF:

<div dir="ltr">

```bash
cut -f1,3,4,5,7 small.gff
```

</div>

<div dir="ltr">

```text
NC_000913.3	region	1	4641652	+
NC_000913.3	gene	190	255	+
NC_000913.3	CDS	190	255	+
NC_000913.3	gene	337	2799	+
NC_000913.3	CDS	337	2799	+
NC_000913.3	gene	2801	3733	+
NC_000913.3	CDS	2801	3733	+
NC_000913.3	gene	3734	5020	+
```

</div>

**این خروجی یعنی:** خط یکم (`region`) کل کروموزوم است، از ۱ تا ۴٬۶۴۱٬۶۵۲. سپس هر ژن دو بار آمده: یک بار به‌عنوان `gene` و یک بار به‌عنوان `CDS` (بخشی که به پروتئین ترجمه می‌شود).

## ۴. الگوی طلایی: `cut | sort | uniq -c`

پرسش «از هر نوع چندتا داریم؟» آن‌قدر رایج است که الگوی ثابتی دارد. آن را **گام‌به‌گام** روی فایل کوچک می‌سازیم تا ببینیم هر بخش چه می‌کند.

**گام ۱: تنها ستون نوع را بردار.**

<div dir="ltr">

```bash
cut -f3 small.gff
```

</div>

<div dir="ltr">

```text
region
gene
CDS
gene
CDS
gene
CDS
gene
```

</div>

**گام ۲: مرتب کن** تا همانندها کنار هم بیایند.

<div dir="ltr">

```bash
cut -f3 small.gff | sort
```

</div>

<div dir="ltr">

```text
CDS
CDS
CDS
gene
gene
gene
gene
region
```

</div>

**گام ۳: همانندهای کنار هم را بشمار.**

<div dir="ltr">

```bash
cut -f3 small.gff | sort | uniq -c
```

</div>

<div dir="ltr">

```text
      3 CDS
      4 gene
      1 region
```

</div>

با چشم هم می‌شود سنجید: در ۸ خط، ۴ ژن، ۳ CDS و ۱ region بود. ✓

**چرا `sort` لازم است؟** `uniq -c` تنها خط‌های همانندی را می‌شمارد که **پشت سر هم** باشند. بی `sort`، از خروجی گام ۱ هشت ردیف جدا با شمار ۱ می‌گرفتید.

### حالا روی کل فایل

<div dir="ltr">

```bash
grep -v '^#' ecoli_k12.gff | cut -f3 | sort | uniq -c | sort -rn | head -6
```

</div>

<div dir="ltr">

```text
   4506 gene
   4340 CDS
    216 exon
    145 pseudogene
    108 ncRNA
     86 tRNA
```

</div>

- `sort -rn` در پایان، بر پایه‌ی عدد (`-n`) و از بزرگ به کوچک (`-r`) مرتب می‌کند.
- `head -6` تنها ۶ ردیف بالا را نشان می‌دهد.

**پاسخ پرسش یکم:** این ژنوم **۴٬۵۰۶ ژن** دارد (و ۱۴۵ ژن کاذب، که نوع جداگانه‌ای دارند).

<details>
<summary>✋ <b>امتحان کن:</b> با همین الگو بشمارید در <code>small.gff</code> چند خط روی رشته‌ی <code>+</code> است. (ستون رشته کدام است؟)</summary>

ستون ۷ رشته است:

<div dir="ltr">

```bash
cut -f7 small.gff | sort | uniq -c
```

</div>

پاسخ: هر ۸ خط روی `+` هستند (`8 +`).
</details>

## ۵. `grep`: پیدا کردن خط‌ها

`grep` خط‌هایی را نشان می‌دهد که یک الگو در آن‌ها هست:

<div dir="ltr">

```bash
grep 'Name=thr' small.gff | cut -f3,4,5
```

</div>

<div dir="ltr">

```text
gene	190	255
gene	337	2799
gene	2801	3733
gene	3734	5020
```

</div>

چهار ژن *thrL*، *thrA*، *thrB* و *thrC*: ژن‌های ساخت ترئونین که پشت سر هم‌اند.

**گزینه‌های پرکاربرد:**

| گزینه | کار | نمونه |
| :--- | :--- | :--- |
| `-c` | تنها شمار خط‌های یافته | `grep -c '^>' file.fa` (شمار توالی‌ها) |
| `-v` | خط‌هایی که الگو را **ندارند** | `grep -v '^#' file.gff` |
| `-w` | تنها واژه‌ی کامل | `grep -w 'rpoB'` (نه `rpoBC`) |
| `-i` | بی‌توجه به حروف بزرگ و کوچک | `grep -i 'atg'` |
| `-o` | تنها بخش یافته‌شده، نه کل خط | `grep -o 'Name=rpo[A-Z]'` |

**نشانه‌های ویژه در الگو:** `^` یعنی «آغاز خط» و `$` یعنی «پایان خط». پس `'^>'` یعنی «خطی که با `>` آغاز می‌شود»، یعنی خط عنوان FASTA. `[A-Z]` یعنی «یکی از حروف A تا Z».

### پاسخ پرسش سوم: ژن‌های rpo

<div dir="ltr">

```bash
grep -P '\tgene\t' ecoli_k12.gff | grep -oE 'Name=rpo[A-Z]+' | sort | tr '\n' ' '
```

</div>

<div dir="ltr">

```text
Name=rpoA Name=rpoB Name=rpoC Name=rpoD Name=rpoE Name=rpoH Name=rpoN Name=rpoS Name=rpoZ
```

</div>

- `grep -P '\tgene\t'`: خط‌هایی که `gene` میان دو Tab دارند، یعنی در ستون نوع. (`-P` می‌گذارد `\t` را برای Tab بنویسیم.)
- `grep -oE 'Name=rpo[A-Z]+'`: از هر خط تنها بخش `Name=rpo…` را بیرون بکش. `+` یعنی «یک یا چند تا».
- `tr '\n' ' '`: پایان خط‌ها را به فاصله تبدیل کن تا همه در یک خط بیایند.

نُه ژن: rpoA، rpoB (ژن داستان ما)، rpoC و rpoZ زیرواحدهای خود آنزیم‌اند، و rpoD، rpoE، rpoH، rpoN و rpoS فاکتورهای σ گوناگون.

## ۶. `awk`: حساب کردن روی ستون‌ها

`awk` هر خط را به ستون‌ها می‌شکند: `$1` ستون یکم، `$2` ستون دوم و همین‌طور تا پایان. `$0` کل خط است. الگوی کلی:

<div dir="ltr">

```text
awk -F'\t'   'شرط { کار }'   فایل
     │           │      │
     │           │      └── برای خط‌هایی که شرط را دارند، این کار را بکن
     │           └── کدام خط‌ها؟ (اگر ننویسید: همه)
     └── جداکننده‌ی ستون‌ها Tab است
```

</div>

### گام ۱: تنها چاپ ستون‌ها، با شرط

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {print $4, $5, $5-$4+1}' small.gff
```

</div>

<div dir="ltr">

```text
190 255 66
337 2799 2463
2801 3733 933
3734 5020 1287
```

</div>

**این دستور یعنی:** «برای خط‌هایی که ستون سومشان `gene` است، آغاز، پایان و طول را چاپ کن». نخستین طول همان ۶۶ است که در بخش ۲ با دست حساب کردیم. ✓

### گام ۲: شمردن با شرط (پاسخ پرسش دوم)

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {print $7}' ecoli_k12.gff | sort | uniq -c
```

</div>

<div dir="ltr">

```text
   2216 +
   2290 -
```

</div>

**۲٬۲۱۶ ژن روی رشته‌ی مثبت و ۲٬۲۹۰ ژن روی رشته‌ی منفی.** نزدیک به نیمه‌نیمه.

### گام ۳: جمع و میانگین (پاسخ پرسش چهارم)

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {l=$5-$4+1; s+=l; n++} END{printf "n=%d mean=%.1f\n", n, s/n}' ecoli_k12.gff
```

</div>

<div dir="ltr">

```text
n=4506 mean=897.4
```

</div>

**این دستور گام‌به‌گام:**
- برای هر ژن: طول را در `l` بگذار، آن را به جمع `s` بیفزا (`s+=l`)، و یکی به شمارنده‌ی `n` بیفزا (`n++`).
- `END{…}` **پس از آخرین خط** یک بار اجرا می‌شود: شمار و میانگین (`s/n`) را چاپ کن.
- `printf` چاپ با قالب است: `%d` عدد درست و `%.1f` عدد با یک رقم اعشار.

**میانگین طول ژن‌ها ۸۹۷ نوکلئوتید است**، یعنی پروتئینی نزدیک به ۳۰۰ اسیدآمینه.

<details>
<summary>✋ <b>امتحان کن:</b> دستوری بنویسید که شمار ژن‌های روی رشته‌ی منفی را مستقیم بدهد (بی <code>sort | uniq</code>).</summary>

دو شرط را با `&&` (و) پیوند بدهید و خط‌ها را با `wc -l` بشمارید:

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" && $7=="-"' ecoli_k12.gff | wc -l
```

</div>

پاسخ: **2290**. اگر بخش `{…}` را ننویسید، `awk` کل خط را چاپ می‌کند.
</details>

## ۷. `awk` روی FASTQ

در FASTQ هر رید ۴ خط است و **خط دوم** توالی است. `NR` در `awk` شماره‌ی خط است. پس:
- خط‌های توالی: خط‌های ۲، ۶، ۱۰، … یعنی آن‌هایی که باقی‌مانده‌ی تقسیمشان بر ۴ برابر ۲ است: `NR%4==2`.

<div dir="ltr">

```bash
R=../../../03_Metagenomics/data/raw
zcat $R/minigut_R1.fastq.gz | awk 'END{print NR/4}'
zcat $R/minigut_R1.fastq.gz | awk 'NR%4==2 {n++; s+=length($0)} END{print "mean length", s/n}'
```

</div>

<div dir="ltr">

```text
50000
mean length 126
```

</div>

- دستور یکم: پس از آخرین خط، شمار خط‌ها ÷ ۴ = **۵۰٬۰۰۰ رید**. همان چیزی که در درس ۱ با دست تقسیم کردیم.
- دستور دوم: برای هر خط توالی، طولش (`length($0)`) را جمع بزن؛ در پایان میانگین را بده: **۱۲۶ باز**.

## ۸. `sed`: جایگزین کردن متن (یک نمونه)

`sed` متن را هنگام گذر از لوله ویرایش می‌کند. پرکاربردترین شکلش `s/الگو/جایگزین/` است:

<div dir="ltr">

```bash
sed 's/ Escherichia.*//' ecoli_k12.fna | head -n 1
```

</div>

<div dir="ltr">

```text
>NC_000913.3
```

</div>

**یعنی:** از فاصله‌ی پیش از `Escherichia` تا پایان خط را (`.*` = هر چیزی) با هیچ جایگزین کن. خط عنوان کوتاه می‌شود و تنها شناسه می‌ماند. برخی ابزارها با خط عنوان بلند و دارای فاصله مشکل دارند و این کار در بسیاری از موارد لازم می‌شود.

## ۹. سه اشتباه رایج

| اشتباه | چرا مشکل است | به جایش چه کنیم |
| :--- | :--- | :--- |
| `uniq -c` بی `sort` | تنها همانندهای پشت سر هم شمرده می‌شوند و شمارش نادرست است | همیشه `sort \| uniq -c` |
| جستجوی یک توالی با `grep` در FASTA چندخطی | الگویی که روی مرز دو خط افتاده دیده نمی‌شود (پایین را ببینید) | نخست خط‌ها را به هم بچسبانید، یا ابزار ویژه (`seqkit`) به کار ببرید |
| `grep -c N` روی کل FASTQ برای شمردن ریدهای دارای N | خط‌های نام و کیفیت هم جستجو می‌شوند و عدد بی‌معناست | تنها خط‌های توالی: `awk 'NR%4==2 && /N/'` |

**نمونه‌ی واقعی اشتباه دوم.** ژنوم در خط‌های ۸۰ حرفی است. `grep` خط‌به‌خط کار می‌کند، پس `ATG`ای که دو حرفش در پایان یک خط و یک حرفش در آغاز خط بعدی است، دیده نمی‌شود:

<div dir="ltr">

```bash
grep -v '^>' ecoli_k12.fna | grep -o ATG | wc -l                 # روش ساده (نادرست)
grep -v '^>' ecoli_k12.fna | tr -d '\n' | grep -o ATG | wc -l    # نخست خط‌ها را به هم بچسبان
```

</div>

<div dir="ltr">

```text
74355
76282
```

</div>

روش ساده **۱٬۹۲۷ مورد (۲٫۵٪) را گم کرد**، بی هیچ پیام خطایی. `tr -d '\n'` همه‌ی پایان‌خط‌ها را پاک می‌کند تا کل ژنوم یک خط شود.

## ۱۰. جمع‌بندی

- GFF جدولی با ۹ ستون است؛ ستون ۳ نوع، ۴ و ۵ جای آغاز و پایان، و ۷ رشته است.
- `grep` خط‌ها را پیدا می‌کند (`-c` شمار، `-v` وارونه، `-o` تنها بخش یافته‌شده).
- `cut | sort | uniq -c` می‌شمارد «از هر چیز چندتا».
- `awk` روی ستون‌ها شرط می‌گذارد و حساب می‌کند؛ `END{}` پس از آخرین خط اجرا می‌شود.
- در FASTQ خط توالی `NR%4==2` است.
- **پاسخ پرسش‌های داستان:** ۴٬۵۰۶ ژن؛ ۲٬۲۱۶ روی + و ۲٬۲۹۰ روی −؛ ۹ ژن rpo؛ میانگین طول ۸۹۷ نوکلئوتید.

---

<details>
<summary>📘 <b>برای کنجکاوها (اختیاری):</b> الگوهای پیشرفته‌تر در grep و sed</summary>

به الگوهایی مانند `^>` یا `rpo[A-Z]+` **عبارت منظم** (regular expression) می‌گویند. چند نشانه‌ی دیگر:
- `.` یعنی «هر یک نویسه»، و `*` یعنی «صفر یا چند تا از نویسه‌ی پیشین». پس `.*` یعنی «هر چیزی».
- `[0-9]` یعنی یک رقم، و `[^;]+` یعنی «یک یا چند نویسه که `;` نیستند». این دومی برای بیرون کشیدن یک مقدار از ستون ۹ GFF بسیار به کار می‌آید: `grep -oE 'Name=[^;]+'`.
- در `sed` می‌شود بخشی از الگو را با `\(` و `\)` نگه داشت و در جایگزین با `\1` آورد:

<div dir="ltr">

```bash
sed 's/^>\(NC_[0-9.]*\) .*/>\1/' ecoli_k12.fna | head -n 1
```

</div>

این هم همان `>NC_000913.3` را می‌دهد، ولی تنها اگر شناسه با `NC_` آغاز شود.
</details>

| GFF | جدول متنی ۹ ستونی برای فهرست ژن‌ها و چیزهای دیگر روی ژنوم |
| Tab | نویسه‌ی جداکننده‌ی ستون‌ها در GFF و بسیاری از جدول‌های بیوانفورماتیکی |
| `grep` | پیدا کردن خط‌هایی که یک الگو دارند |
| `cut -f` | برداشتن ستون‌ها |
| `sort` / `uniq -c` | مرتب کردن / شمردن خط‌های همانند پشت سر هم |
| `awk` | ابزار حساب و شرط روی ستون‌ها (`$1`، `$2`…، `NR`، `END`) |
| `sed` | ویرایش متن در لوله (`s/الگو/جایگزین/`) |
| عبارت منظم (regex) | زبان کوچکی برای نوشتن الگو (`^`، `$`، `.`، `*`، `[A-Z]`) |
