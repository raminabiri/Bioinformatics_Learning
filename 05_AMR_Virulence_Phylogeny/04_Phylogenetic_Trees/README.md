## اهداف یادگیری
پس از این ماژول می‌توانید:
1. از هم‌ردیفی، درخت maximum likelihood با مدل مناسب بسازید.
2. پشتیبانی شاخه‌ها (bootstrap) را تفسیر کنید.
3. درخت را با metadata (ST، AMR، بیمارستان) نمایش دهید.

## سرفصل درس
1. هم‌ردیفی چندگانه و هم‌ردیفی core
2. مدل‌های جایگزینی و ModelFinder
3. ML، UFBoot و SH-aLRT؛ ریشه‌دار کردن درخت
4. بازترکیب و اثرش بر درخت
5. نمایش با iTOL/ggtree
