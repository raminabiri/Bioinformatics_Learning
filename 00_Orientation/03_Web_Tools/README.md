## اهداف یادگیری
پس از این ماژول می‌توانید:
1. یک توالی DNA را در شش قاب ترجمه کنید و قاب درست را پیدا کنید.
2. خروجی یک هم‌ترازی دوتایی (یکسانی، همانندی، شکاف) را بخوانید.
3. با هم‌ترازی چندتایی ناحیه‌های حفاظت‌شده و جایگاه‌های همتا را در باکتری‌های گوناگون پیدا کنید.
4. ستون‌های مهم خروجی BLAST (یکسانی، پوشش، E value) را تفسیر کنید.
