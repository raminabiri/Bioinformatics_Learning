## اهداف یادگیری
پس از این ماژول می‌توانید:
1. زیرشاخه‌های اصلی بیوانفورماتیک را با نوع داده، سؤال زیستی و ابزار شاخص هرکدام نام ببرید.
2. هر پروژه‌ی تحلیلی را به مراحل استاندارد «سؤال ← داده ← QC ← پردازش ← تحلیل ← تفسیر» بشکنید.
3. بخش Methods یک مقاله را از نظر **تکرارپذیری** نقد کنید (نسخه‌ی ابزار، پارامتر، شناسه‌ی داده، کد).
4. اصول FAIR را توضیح دهید و بگویید داده‌ی خودتان را چطور FAIR منتشر کنید.
