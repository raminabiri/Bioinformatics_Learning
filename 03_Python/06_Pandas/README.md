پس از این ماژول می‌توانید:
1. جدول TSV را در DataFrame بخوانید و ساختار و آمار توصیفی‌اش را ببینید.
2. سطرها را گزینش و مرتب کنید، با `groupby` خلاصه کنید و ستون تازه بسازید.

4. هیستوگرام و نمودار میله‌ای بکشید و در PNG ذخیره کنید.
