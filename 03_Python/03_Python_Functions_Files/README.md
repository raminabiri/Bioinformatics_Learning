## اهداف یادگیری
پس از این ماژول می‌توانید:
1. تابع بنویسید (`def`، `return`، docstring) و تفاوت `return` و `print` را بدانید.
2. فایل را خط‌به‌خط بخوانید، به ستون بشکنید و جدول TSV یا BED بنویسید.
3. یک خواننده‌ی ساده‌ی FASTA بنویسید و یک ژن را از ژنوم ببرید.
4. نام فایل‌ها را با `sys.argv` از ترمینال به اسکریپت بدهید.
