## اهداف یادگیری
پس از این ماژول می‌توانید:
1. پایتون را در حالت تعاملی (REPL) باز کنید و با آن حساب کنید.
2. متغیر بسازید و با رشته‌ی DNA کار کنید: طول، برش، شمردن، جایگزینی.
3. خروجی را با f-string قالب‌بندی کنید و نخستین اسکریپت `.py` خود را اجرا کنید.
4. پیام‌های خطای رایج (`NameError`، `TypeError`، `IndexError`، `SyntaxError`) را بخوانید.
