## اهداف یادگیری
پس از این ماژول می‌توانید:
1. منطق MLST (۷ ژن خانه‌دار، آلل، ST) و محدودیت تفکیک آن را توضیح دهید.
2. ‏`mlst` را اجرا کنید و نشانه‌های آلل تازه، ناقص، گمشده و چندگانه را تفسیر کنید.
3. ‏ST، کمپلکس کلونال و کلون‌های پرخطر (*E. coli* ST131، *K. pneumoniae* ST258) را بشناسید.
4. بگویید کِی MLST بس است و کِی cgMLST یا SNP لازم است.
