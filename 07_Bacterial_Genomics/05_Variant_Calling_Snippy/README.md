## اهداف یادگیری
پس از این ماژول می‌توانید:
1. SNP و indel ایزوله‌ها را نسبت به مرجع فراخوانی کنید.
2. جهش‌های rpoB و gyrA مرتبط با مقاومت را پیدا و تفسیر کنید.
3. هم‌ردیفی core SNP برای فیلوژنی بسازید (ورودی بخش ۰۸).

## سرفصل درس
1. انتخاب مرجع و اثرش
2. Snippy: mapping، فیلترها، VCF و آنوتیشن اثر
3. snippy-core و حذف نواحی بازترکیب (اشاره به Gubbins)
4. تفسیر جهش‌ها: ناحیه‌ی RRDR در rpoB و QRDR در gyrA

## تمرین‌های برنامه‌ریزی‌شده
- جدول جهش‌های rpoB و gyrA همه‌ی ایزوله‌ها با تغییر اسیدآمینه
- ماتریس فاصله‌ی SNP و پاسخ به سؤال «آیا انتقال رخ داده؟»
