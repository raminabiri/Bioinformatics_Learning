## اهداف یادگیری
پس از این ماژول می‌توانید:
1. پایپلاین nf-core را با پروفایل و کانتینر اجرا و پارامترها را مستند کنید.
2. کانتینر Docker/Apptainer بسازید و استفاده کنید.
3. کار را روی کلاستر SLURM ارسال و منابع را تنظیم کنید.

## سرفصل درس
1. Nextflow: process، channel، config، resume
2. nf-core: اجرای nf-core/mag روی داده‌ی بخش ۰۳ (همان داده‌ی تست رسمی‌اش)
3. کانتینرها و تکرارپذیری محیط
4. SLURM: sbatch، آرایه‌ها، درخواست منابع
