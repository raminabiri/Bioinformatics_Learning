## اهداف یادگیری
پس از این ماژول می‌توانید:
1. یک گردش کار مبتنی بر LLM برای خلاصه‌سازی گزارش‌ها طراحی کنید.
2. خروجی LLM را با داده‌ی واقعی اعتبارسنجی کنید (پیشگیری از hallucination).
