# دوره‌ی عملی بیوانفورماتیک (Bioinformatics — From Data to Insight)

دوره‌ی خودآموز و عملی بیوانفورماتیک به زبان فارسی، برای **دانشجویان کارشناسی ارشد و دکتری** زیست‌شناسی، میکروب‌شناسی، پزشکی و زیست‌فناوری. فرض دوره این است که خواننده مفاهیم پایه‌ی زیست‌شناسی مولکولی (DNA، ژن، پروتئین، PCR) را می‌داند. تمرکز روی **داده، ابزار، تصمیم‌گیری تحلیلی و تکرارپذیری** است.

---

## نحوه‌ی استفاده

1. بخش‌ها را **به ترتیب شماره** پیش بروید؛ هر ماژول پیش‌نیازهایش را در `README.md` خودش اعلام می‌کند.
2. در هر ماژول فایل‌ها به ترتیب شماره خوانده می‌شوند: `README.md` ← `01_lesson…` ← `02_exercises` ← (حل کنید) ← `03_solutions`. اگر ماژول دو درس دارد، شماره‌ها ادامه پیدا می‌کنند (`01_lesson_…`، `02_lesson_…`، `03_exercises`، `04_solutions`).
3. همه‌ی دستورها را **خودتان در ترمینال اجرا کنید**؛ خروجی‌های ذکرشده در درس‌ها واقعی‌اند و باید با خروجی شما (تقریباً) یکسان باشند.
4. خروجی‌های کار خود را در پوشه‌ی `work/` هر بخش بسازید (این پوشه در git ثبت نمی‌شود).

## نصب محیط کار

```bash
# یک‌بار برای کل دوره (بخش‌های ۰۰، ۰۱ و ۰۳)
mamba env create -f envs/bioinfo_course.yml
conda activate bioinfo_course
```

> اگر دسترسی به `conda.anaconda.org` کند یا قطع است، راه جایگزین در [envs/README.md](envs/README.md) آمده است.

### چرا این ترتیب؟

- **۰۰ قبل از همه:** پیش از یادگرفتن ابزار، باید بدانید داده از کجا می‌آید و هر ابزار کجای نقشه‌ی رشته است.
- **برنامه‌نویسی (۰۲) قبل از تحلیل‌های تخصصی:** در متاژنومیکس و ژنومیکس، خروجی ابزارها جدول است و تحلیل آماری و رسم نمودار با Python/R انجام می‌شود. بدون آن، تحلیل به کپی‌کردن دستور تقلیل پیدا می‌کند.
- **۰۳ ← ۰۴ ← ۰۵:** از جامعه‌ی میکروبی (متاژنوم) به ژنوم تک‌باکتری، و از آن به ویژگی‌های بالینی (مقاومت، ضراوت، تکامل) می‌رسیم. یک **ژن رشته‌ی مشترک** (rpoB و مقاومت به ریفامپیسین) از بخش ۰۰ تا ۰۵ دنبال می‌شود.
- **۰۶ و ۰۷** موضوعات مستقل‌تر و پیشرفته‌ترند.
