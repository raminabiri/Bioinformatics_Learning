# دوره‌ی کاربردی بیوانفورماتیک (Bioinformatics — From Data to Insight)

دوره‌ی خودآموز بیوانفورماتیک به زبان فارسی، برای کسی که **زیست‌شناسی پایه و مولکولی را می‌داند ولی بیوانفورماتیک بلد نیست**: دانشجویان زیست‌شناسی، میکروب‌شناسی، پزشکی و زیست‌فناوری. هر مفهوم بیوانفورماتیکی از صفر، با نمونه‌ی کوچک و داده‌ی واقعی توضیح داده می‌شود. هر درس کادرهای «✋ امتحان کن» دارد، و هر ماژول تمرین‌های پایه‌ای با راهنمایی و پاسخ تشریحی دارد.

**آموزش پله‌به‌پله است:** هیچ درسی چیزی را به کار نمی‌برد که پیش‌تر درس داده نشده باشد. بخش ۰۰ تنها مرورگر می‌خواهد؛ ترمینال از بخش ۰۱، نصب ابزارهای زیستی از بخش ۰۲، و برنامه‌نویسی از بخش ۰۳ آغاز می‌شود.

---

## روش به کار بردن دوره

1. بخش‌ها را **به ترتیب شماره** پیش بروید؛ هر ماژول پیش‌نیازهایش را در `README.md` خودش می‌گوید.
2. در هر ماژول نخست `README.md` را بخوانید، سپس درس‌ها (`01_lesson…`)، سپس تمرین‌ها (خودتان حل کنید)، و در پایان پاسخ‌ها.
3. اسکریپت‌ها و داده‌ی هر بخش در پوشه‌ی `99_scripts_data` در پایان همان بخش‌اند.
4. همه‌ی دستورها را **خودتان در ترمینال اجرا کنید**؛ خروجی‌های درس‌ها واقعی‌اند و باید با خروجی شما کمابیش یکسان باشند.

### چرا این ترتیب؟

- **۰۰ پیش از همه، بی ترمینال:** نخست باید بدانید بیوانفورماتیک چه می‌کند و داده از کجا می‌آید. با ابزارهای وب، کار بیوانفورماتیکی واقعی را پیش از نخستین دستور تجربه می‌کنید.
- **۰۱ لینوکس ← ۰۲ بایولینوکس:** نخست ترمینال و ابزارهای خود لینوکس؛ سپس نصب و به‌کارگیری ابزارهای زیستی.
- **۰۳ پایتون ← ۰۴ بسته‌های R:** پایتون از صفر آموزش داده می‌شود. از R تنها **اجرای** بسته‌های آماده‌ی بیوانفورماتیک (DESeq2، vegan، ggtree) آموزش داده می‌شود؛ زبان R و آمار موضوع دوره‌ای جداگانه است. در بخش‌های بعد، خروجی بیشتر ابزارها جدول است و با همین مهارت‌ها تحلیل می‌شود.
- **۰۵ کار دوباره‌پذیر:** Git و Snakemake پس از برنامه‌نویسی می‌آیند، چون Snakemake بر پایه‌ی پایتون است.
- **۰۶ ← ۰۷ ← ۰۸:** از جامعه‌ی میکروبی (متاژنوم) به ژنوم تک‌باکتری، و از آن به ویژگی‌های بالینی (مقاومت، بیماری‌زایی، تکامل). یک **رشته‌ی مشترک** (ژن rpoB و مقاومت به ریفامپیسین) از بخش ۰۰ تا ۰۸ دنبال می‌شود.
- **۰۹ و ۱۰** موضوع‌های مستقل‌تر و پیشرفته‌ترند.
