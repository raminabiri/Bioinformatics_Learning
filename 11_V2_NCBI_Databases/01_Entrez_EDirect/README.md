## اهداف یادگیری
پس از این ماژول می‌توانید:
1. ساختار Entrez و پیوند میان پایگاه‌ها را توضیح دهید.
2. با EDirect جست‌وجو، دریافت و پیوند را در یک لوله انجام دهید.
3. قاعده‌های بار سرور و کلید API را رعایت کنید.

## سرفصل
1. نقشه‌ی Entrez: پایگاه‌ها و پیوندها
2. ‏E-utilities با `curl`
3. ‏EDirect و `xtract` برای جدول‌سازی
4. کلید API، محدودیت سرعت و تکرارپذیری
