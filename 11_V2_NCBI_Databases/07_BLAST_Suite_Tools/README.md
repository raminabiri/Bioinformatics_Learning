## اهداف یادگیری
پس از این ماژول می‌توانید:
1. گونه‌ی BLAST درست را برای هر پرسش برگزینید.
2. ‏E-value، bit score و پوشش را درست بخوانید.
3. برای یک ژن آغازگر PCR طراحی و سنجش کنید.
