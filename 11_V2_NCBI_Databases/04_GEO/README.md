## اهداف یادگیری
پس از این ماژول می‌توانید:
1. ساختار رکوردهای GEO (GSE، GSM، GPL، GDS) را بشناسید.
2. ‏series matrix و جدول شمارش آماده‌ی NCBI را بگیرید و با pandas بخوانید.
3. با CPM و log2FC جفتی پاسخ معلوم را بسنجید.
4. با GEO2R یک مقایسه‌ی سریع بسازید و محدودیتش را بگویید.
