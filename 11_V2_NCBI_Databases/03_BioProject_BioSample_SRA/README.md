## اهداف یادگیری
پس از این ماژول می‌توانید:
1. سلسله‌مراتب BioProject، BioSample، Experiment و Run را توضیح دهید.
2. جدول runinfo یک پروژه را بگیرید و پیش از دانلود حجم و گونه‌ی داده را بسنجید.

4. ریدها را با SRA Toolkit بگیرید، درستی‌شان را بسنجید و با ENA مقایسه کنید.
