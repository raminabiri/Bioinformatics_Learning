# 🔑 پاسخ‌نامه تشریحی تمرین‌های جلسه دوم

---

### 💡 پاسخ سوال ۱
```bash
# ۱. ایجاد پوشه مقصد
mkdir -p ~/miniconda3

# ۲. دانلود اسکریپت نصب
wget [https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh](https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh) -O ~/miniconda3/miniconda.sh

# ۳. اجرای نصب‌کننده در حالت خودکار (-b) و آپدیت (-u)
bash ~/miniconda3/miniconda.sh -b -u -p ~/miniconda3

# ۴. حذف اسکریپت نصب جهت پاک‌سازی
rm -rf ~/miniconda3/miniconda.sh

# ۵. راه‌اندازی اولیه برای پوسته Bash
~/miniconda3/bin/conda init bash
