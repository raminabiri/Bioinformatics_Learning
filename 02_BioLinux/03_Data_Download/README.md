## اهداف یادگیری
پس از این ماژول می‌توانید:
1. بگویید چرا داده را باید با دستور دریافت کرد، نه با کلیک در مرورگر.
2. یک ژنوم را با `datasets` از NCBI بگیرید.
3. از API پایگاه‌ها (ENA، UniProt) با `curl` بپرسید و درستی دانلود را با md5 بسنجید.
4. یک ژن را با یک اسکریپت در هشت پایگاه داده دنبال کنید.
