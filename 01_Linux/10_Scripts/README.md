پس از این ماژول می‌توانید:
1. دستورها را در یک اسکریپت با ورودی بنویسید و اجرا کنید.
2. اسکریپت را با set -euo pipefail ایمن کنید.
3. کار طولانی را با nohup یا tmux اجرا کنید.
