## اهداف یادگیری
پس از این ماژول می‌توانید:
1. بگویید چرا بیوانفورماتیک در بسیاری از موارد روی لینوکس انجام می‌شود.
2. روی ویندوز (WSL)، مک یا لینوکس یک ترمینال آماده کنید، یا با `ssh` به سرور وصل شوید.
3. نخستین دستورها را اجرا کنید و نسخه‌ی ابزارها را بخوانید.
4. فایل‌های دوره را با `curl` و `unzip` بگیرید.
