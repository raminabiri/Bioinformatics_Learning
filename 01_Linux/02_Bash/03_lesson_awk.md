## در یک نگاه

**در پایان این درس می‌توانید:**
1. بگویید `awk` چیست و یک فایل را چگونه خط‌به‌خط و ستون‌به‌ستون می‌خواند.
2. یک یا چند ستون را چاپ کنید و جداکننده‌ی ستون‌ها را درست تعیین کنید.
3. با **شرط** تنها خط‌هایی را بردارید که می‌خواهید.
4. روی ستون‌ها **حساب** کنید: طول ژن، جمع، شمار، میانگین.
5. با `END` نتیجه را پس از خواندن همه‌ی خط‌ها چاپ کنید و با `printf` آن را قالب‌بندی کنید.
6. با `NR` تنها خط‌های توالی یک FASTQ را بردارید.

## ۱. داستان: پرسش‌هایی که شمردن کافی نیست

در درس ۲ با `cut | sort | uniq -c` شمردیم «از هر نوع چندتا داریم». ولی این پرسش‌ها **حساب** می‌خواهند:
- طول هر ژن چقدر است؟ (پایان − آغاز + ۱)
- میانگین طول ژن‌ها چقدر است؟
- بلندترین ژن‌ها کدام‌اند؟
- میانگین طول ریدهای یک FASTQ چقدر است؟

‏`cut` تنها ستون جدا می‌کند و نمی‌تواند تفریق یا جمع کند. برای این کارها ابزاری لازم است که هم ستون‌ها را بشناسد و هم حساب کند: **`awk`**.

## ‏۲. awk چیست؟

‏`awk` یک زبان برنامه‌نویسی کوچک است که برای کار با **جدول‌های متنی** ساخته شده. کارش را با یک تشبیه ببینید:

> کارمندی را تصور کنید که یک جدول را **ردیف‌به‌ردیف** می‌خواند. شما به او یک دستورکار می‌دهید: «برای هر ردیفی که فلان ویژگی را دارد، فلان کار را بکن.» او ردیف یکم را می‌خواند، دستورکار را اجرا می‌کند، سپس ردیف دوم، و همین‌طور تا آخر.

‏`awk` همین کارمند است. هر خط فایل یک **ردیف** است و هر ردیف به **ستون‌ها** (به زبان awk، «فیلدها») شکسته می‌شود:

| نام در awk | یعنی |
| :--- | :--- |
| `$1` | ستون یکم |
| `$2` | ستون دوم |
| … | … |
| `$9` | ستون نهم |
| `$0` | کل خط |
| `NF` | شمار ستون‌های این خط |
| `NR` | شماره‌ی این خط (۱، ۲، ۳، …) |

⚠️ `$1` در `awk` معنایی جدا از `$R` در Bash دارد. در `awk` نشانه‌ی `$` یعنی «ستونِ شماره‌ی …». به همین دلیل برنامه‌ی `awk` را **همیشه در نقل‌قول تکی** (`'…'`) می‌نویسیم تا Bash به `$`های آن دست نزند (بخش ۹ را ببینید).

## ۳. نخستین دستور: چاپ یک ستون

## ۴. جداکننده‌ی ستون‌ها: چرا `-F'\t'` لازم است

اگر جداکننده را نگویید، `awk` هر **فاصله یا Tab** را مرز ستون می‌گیرد. در GFF ستون‌ها با **Tab** جدا شده‌اند، ولی ستون نهم خودش **فاصله** دارد (برای نمونه `product=thr operon leader peptide`). ببینید چه می‌شود. `NR==3` یعنی «تنها خط سوم» (بخش ۶ و ۸):

<div dir="ltr">

```bash
awk 'NR==3 {print $9}' small.gff
```

</div>

<div dir="ltr">

```text
ID=cds-NP_414542.1;Parent=gene-b0001;Dbxref=...;gene=thrL;locus_tag=b0001;product=thr
```

</div>

ستون نهم **وسط واژه بریده شد**: پس از `product=thr` یک فاصله بود و `awk` گمان کرد ستون تمام شده است. حالا با `-F'\t'`:

<div dir="ltr">

```bash
awk -F'\t' 'NR==3 {print $9}' small.gff
```

</div>

<div dir="ltr">

```text
ID=cds-NP_414542.1;Parent=gene-b0001;Dbxref=...;gene=thrL;locus_tag=b0001;product=thr operon leader peptide;protein_id=NP_414542.1;transl_table=11
```

</div>

(بخش میانی را با `...` کوتاه کرده‌ایم.)

### کالبدشکافی `-F'\t'`

| بخش | یعنی |
| :--- | :--- |
| `-F` | گزینه‌ی «جداکننده‌ی ستون‌ها (Field separator) این است» |
| `'\t'` | نویسه‌ی Tab (نقل‌قول تکی تا Bash به `\` دست نزند) |

**سنجش با `NF`:** شمار ستون‌های هر خط را ببینید:

<div dir="ltr">

```bash
awk '{print NF}' small.gff | head -n 3
awk -F'\t' '{print NF}' small.gff | head -n 3
```

</div>

<div dir="ltr">

```text
10
9
12
9
9
9
```

</div>

بی `-F'\t'`، خط‌ها ۱۰ یا ۱۲ ستون دارند (فاصله‌های ستون نهم ستون‌های ساختگی ساخته‌اند). با `-F'\t'` هر خط دقیقاً **۹ ستون** دارد، درست همان‌طور که GFF تعریف شده است.

**قاعده: برای GFF، BED، VCF و هر جدول Tab‌دار، همیشه `-F'\t'` بنویسید.**

## ۵. شرط: تنها خط‌هایی که می‌خواهیم

ساختار کامل برنامه‌ی awk این است:

<div dir="ltr">

```text
شرط { کار }
```

</div>

‏`awk` برای هر خط: اگر **شرط** درست بود، **کار** را انجام می‌دهد.

### گام ۱: تنها شرط

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene"' small.gff
```

</div>

<div dir="ltr">

```text
NC_000913.3	RefSeq	gene	190	255	.	+	.	ID=gene-b0001;...
NC_000913.3	RefSeq	gene	337	2799	.	+	.	ID=gene-b0002;...
NC_000913.3	RefSeq	gene	2801	3733	.	+	.	ID=gene-b0003;...
NC_000913.3	RefSeq	gene	3734	5020	.	+	.	ID=gene-b0004;...
```

</div>

#### کالبدشکافی `$3=="gene"`

| بخش | یعنی |
| :--- | :--- |
| `$3` | ستون سوم این خط |
| `==` | «برابر است با؟» (دو نشانه‌ی مساوی؛ بخش ۹ را ببینید) |
| `"gene"` | متن `gene`. متن را در awk در **نقل‌قول دوتایی** می‌نویسیم؛ عدد را بی نقل‌قول. |

وقتی **کار** ننویسید، `awk` کار پیش‌فرض را انجام می‌دهد: **کل خط را چاپ می‌کند**. پس این دستور همان کار `grep` را می‌کند، ولی دقیق‌تر: تنها ستون سوم را می‌سنجد، نه کل خط را.

### گام ۲: شرط + کار

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {print $4, $5}' small.gff
```

</div>

<div dir="ltr">

```text
190 255
337 2799
2801 3733
3734 5020
```

</div>

**این خروجی یعنی:** برای هر ژن، آغاز و پایانش.

### ویرگول در `print`

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {print $4 $5}' small.gff
```

</div>

<div dir="ltr">

```text
190255
3372799
28013733
37345020
```

</div>

بی ویرگول، دو مقدار **به هم چسبیدند**. ویرگول در `print` یعنی «میان این دو یک فاصله بگذار».

### شرط‌های دیگر

| شرط | یعنی |
| :--- | :--- |
| `$7=="-"` | روی رشته‌ی منفی |
| `$4 > 1000000` | آغاز پس از یک میلیون |
| `$5-$4+1 < 100` | طول کمتر از ۱۰۰ |
| `$3=="gene" && $7=="-"` | هر دو شرط (`&&` یعنی «و») |
| `$3=="tRNA" \|\| $3=="rRNA"` | یکی از دو شرط (`\|\|` یعنی «یا») |
| `$9 ~ /Name=gyrA;/` | ستون ۹ این **الگو** را دارد (`~` یعنی «دارد»؛ الگو میان دو `/` است، همان الگوهای `grep` در درس ۲) |

<details>
<summary>✋ <b>امتحان کن:</b> در کل ژنوم چند ژن کوتاه‌تر از ۱۰۰ نوکلئوتید هست؟</summary>

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" && $5-$4+1 < 100' ecoli_k12.gff | wc -l
```

</div>

پاسخ: **230**. شرط دو بخش دارد که با `&&` به هم پیوسته‌اند؛ چون کاری ننوشتیم، خط‌ها کامل چاپ و با `wc -l` شمرده شدند.
</details>

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {print $4, $5, $5-$4+1}' small.gff
```

</div>

<div dir="ltr">

```text
190 255 66
337 2799 2463
2801 3733 933
3734 5020 1287
```

</div>

**`$5-$4+1`:** پایان منهای آغاز به‌اضافه‌ی یک. «+۱» لازم است چون هر دو سر جزو ژن‌اند (درس ۲، بخش ۲). نخستین ژن (*thrL*) ۶۶ نوکلئوتید است، همان عددی که در درس ۲ با دست حساب کردیم. ✓

‏`awk` این نشانه‌های حساب را می‌شناسد: `+`، `-`، `*`، `/`، و `%` (باقی‌مانده‌ی تقسیم؛ بخش ۸).

## ۷. متغیر، جمع و شمار

برای میانگین به **جمع طول‌ها** و **شمار ژن‌ها** نیاز داریم. پس `awk` باید از یک خط به خط بعدی چیزی را **به یاد بسپارد**. این کار را با **متغیر** می‌کند.

### گام ۱: سه متغیر

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {l=$5-$4+1; s+=l; n++; print l, s, n}' small.gff
```

</div>

#### کالبدشکافی بخش «کار»

| تکه | یعنی | به زبان ساده |
| :--- | :--- | :--- |
| `l=$5-$4+1` | طول را در متغیر `l` بگذار | «طول این ژن را یادداشت کن» |
| `;` | جداکننده‌ی دو فرمان | «و سپس» |
| `s+=l` | ‏`l` را به `s` بیفزا (کوتاه‌شده‌ی `s=s+l`) | «طول را به جمع کل اضافه کن» |
| `n++` | یکی به `n` بیفزا (کوتاه‌شده‌ی `n=n+1`) | «یک ژن دیگر شمردم» |
| `print l, s, n` | هر سه را چاپ کن | تنها برای این‌که ببینیم چه می‌گذرد |

**نکته:** در `awk` لازم نیست متغیر را پیش‌تر بسازید. نخستین بار که به کار می‌رود، مقدارش **صفر** است.

### خروجی

<div dir="ltr">

```text
66 66 1
2463 2529 2
933 3462 3
1287 4749 4
```

</div>

### دنبال کردن خط‌به‌خط

| خط فایل | نوع | شرط درست است؟ | `l` | `s` | `n` |
| :-: | :--- | :-: | ---: | ---: | ---: |
| ۱ | region | ❌ | — | 0 | 0 |
| ۲ | gene | ✅ | 66 | 0 + 66 = **66** | **1** |
| ۳ | CDS | ❌ | | 66 | 1 |
| ۴ | gene | ✅ | 2463 | 66 + 2463 = **2529** | **2** |
| ۵ | CDS | ❌ | | 2529 | 2 |
| ۶ | gene | ✅ | 933 | 2529 + 933 = **3462** | **3** |
| ۷ | CDS | ❌ | | 3462 | 3 |
| ۸ | gene | ✅ | 1287 | 3462 + 1287 = **4749** | **4** |

‏`s` مانند یک **قلک** است: با هر ژن پرتر می‌شود. `n` مانند یک **شمارنده‌ی دستی** است: با هر ژن یکی بالا می‌رود.

## ‏۸. `END`: پس از آخرین خط

ما تنها جمع و شمار **نهایی** را می‌خواهیم، نه پس از هر ژن. `END{…}` کاری است که **یک بار، پس از خواندن همه‌ی خط‌ها** انجام می‌شود:

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {l=$5-$4+1; s+=l; n++} END{print n, s, s/n}' small.gff
```

</div>

<div dir="ltr">

```text
4 4749 1187.25
```

</div>

### کالبدشکافی

<div dir="ltr">

```text
awk -F'\t'   '$3=="gene" {l=$5-$4+1; s+=l; n++}    END{print n, s, s/n}'   small.gff
                └───────── برای هر خط ──────────┘    └── یک بار در پایان ──┘
```

</div>

**این خروجی یعنی:** ۴ ژن، جمع طول ۴٬۷۴۹، میانگین ۱٬۱۸۷٫۲۵ نوکلئوتید. `print` درون آکولاد نخست را برداشتیم، پس خروجی میانی دیگر چاپ نشد.

### ‏`printf`: چاپ مرتب

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {l=$5-$4+1; s+=l; n++} END{printf "n=%d mean=%.1f\n", n, s/n}' small.gff
```

</div>

<div dir="ltr">

```text
n=4 mean=1187.2
```

</div>

#### کالبدشکافی `printf "n=%d mean=%.1f\n", n, s/n`

| تکه | یعنی |
| :--- | :--- |
| `printf` | «چاپ با الگو» (print + format) |
| `"n=%d mean=%.1f\n"` | الگو: متن ثابت، با دو **جای خالی** |
| `%d` | جای خالی یکم: یک عدد **درست** (بی اعشار) |
| `%.1f` | جای خالی دوم: یک عدد **اعشاری با ۱ رقم** پس از ممیز |
| `\n` | پایان خط (`printf` برخلاف `print` خودش به خط بعد نمی‌رود) |
| `, n, s/n` | مقدارهایی که به ترتیب در جای خالی‌ها می‌نشینند |

### حالا روی کل ژنوم

همان دستور، تنها با فایل بزرگ:

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {l=$5-$4+1; s+=l; n++} END{printf "n=%d mean=%.1f\n", n, s/n}' ecoli_k12.gff
```

</div>

<div dir="ltr">

```text
n=4506 mean=897.4
```

</div>

**۴٬۵۰۶ ژن، با میانگین طول ۸۹۷ نوکلئوتید** (پروتئینی نزدیک به ۳۰۰ اسیدآمینه).

<details>
<summary>✋ <b>امتحان کن:</b> همین دستور را طوری عوض کنید که میانگین طول <b>tRNA</b>ها را بدهد.</summary>

تنها شرط عوض می‌شود: `$3=="tRNA"`.

<div dir="ltr">

```bash
awk -F'\t' '$3=="tRNA" {l=$5-$4+1; s+=l; n++} END{printf "n=%d mean=%.1f\n", n, s/n}' ecoli_k12.gff
```

</div>

پاسخ: `n=86 mean=78.5`. tRNAها نزدیک به ۷۶ تا ۹۰ نوکلئوتیدند، پس این عدد درست به نظر می‌رسد.
</details>

## ‏۹. `NR`: شماره‌ی خط، و FASTQ

در FASTQ هر رید ۴ خط است و **خط دوم** توالی است. پس برای میانگین طول ریدها باید تنها خط‌های ۲، ۶، ۱۰، … را برداریم. این‌جا `NR` (شماره‌ی خط) و `%` (باقی‌مانده‌ی تقسیم) به کار می‌آیند.

### `%` چیست؟
‏`a % b` یعنی «باقی‌مانده‌ی تقسیم a بر b». برای نمونه `6 % 4 = 2` (۶ تقسیم بر ۴، یک و باقی ۲). ببینید `NR%4` برای ۸ خط اول FASTQ چیست:

<div dir="ltr">

```bash
zcat fastq/minigut_R1.fastq.gz | head -n 8 | awk '{print NR, NR%4, substr($0,1,30)}'
```

</div>

<div dir="ltr">

```text
1 1 @NC_006347.1_0/1
2 2 AACGTTGGCTCGTCTGACAAGCAAAGGTAA
3 3 +
4 0 BBBBBFFFFFFFFFFFFFFFFFF/FFFFFF
5 1 @NC_006347.1_1/1
6 2 CGCAAAGCCAGCTTCGCGAATTGATCCGCC
7 3 +
8 0 BBBBBFFFFFFFFFFFFFFFFFFFFFFFFF
```

</div>

‏(`substr($0,1,30)` یعنی «۳۰ نویسه‌ی اول خط»؛ تنها برای کوتاه شدن خروجی.)

**این خروجی یعنی:** `NR%4` الگوی ۱، ۲، ۳، ۰ را تکرار می‌کند. هر جا `NR%4` برابر **۲** است، خط **توالی** است. پس شرط `NR%4==2` دقیقاً خط‌های توالی را برمی‌دارد.

### میانگین طول ریدها

<div dir="ltr">

```bash
zcat fastq/minigut_R1.fastq.gz | awk 'NR%4==2 {n++; s+=length($0)} END{print "reads:", n, "mean length:", s/n}'
```

</div>

<div dir="ltr">

```text

```

#### کالبدشکافی

| تکه | یعنی |
| :--- | :--- |
| `zcat … \|` | فایل فشرده را باز کن و به `awk` بده؛ این بار `awk` ورودی را از لوله می‌گیرد، نه از نام فایل |
| `NR%4==2` | شرط: تنها خط‌های توالی |
| `n++` | شمار ریدها |
| `s+=length($0)` | طول خط (`length`) را به جمع بیفزا |
| `END{print …}` | در پایان: شمار و میانگین. متن‌های ثابت در `"…"`‌اند |

جداکننده‌ی `-F` این‌جا لازم نیست، چون به ستون‌ها کاری نداریم و با کل خط (`$0`) کار می‌کنیم.

## ۱۰. سه اشتباه رایج (با خروجی واقعی‌شان)

### اشتباه ۱: یک `=` به جای دو `==`

<div dir="ltr">

```bash
awk -F'\t' '$3="gene" {print $3}' small.gff | head -n 3
```

</div>

<div dir="ltr">

```text
gene
gene
gene
```

</div>

**خط یکم (`region`) هم «gene» شد!** `=` یعنی «بگذار»، نه «بسنج». این دستور ستون سوم **هر** خط را به `gene` تغییر داد و همه را چاپ کرد، بی هیچ پیام خطایی. همیشه برای سنجش `==` بنویسید.

### اشتباه ۲: نقل‌قول دوتایی به جای تکی دور برنامه

<div dir="ltr">

```bash
awk -F'\t' "{print $3}" small.gff | head -n 2
```

</div>

<div dir="ltr">

```text
NC_000913.3	RefSeq	region	1	4641652	.	+	.	ID=NC_000913.3:1..
NC_000913.3	RefSeq	gene	190	255	.	+	.	ID=gene-b0001;Dbxref=E
```

</div>

به جای ستون سوم، **کل خط** چاپ شد. چرا؟ در نقل‌قول دوتایی، **Bash** پیش از `awk` نشانه‌ی `$3` را می‌بیند و آن را با «سومین ورودی اسکریپت» جایگزین می‌کند که خالی است. پس `awk` تنها `{print }` را می‌گیرد که کل خط را چاپ می‌کند. **برنامه‌ی awk را همیشه در نقل‌قول تکی بنویسید.**

### اشتباه ۳: شرطی که هیچ خطی را برنمی‌دارد

<div dir="ltr">

```bash
awk -F'\t' '$3=="genes" {l=$5-$4+1; s+=l; n++} END{printf "n=%d mean=%.1f\n", n, s/n}' small.gff
```

</div>

<div dir="ltr">

```text
awk: cmd. line:1: (FILENAME=small.gff FNR=8) fatal: division by zero attempted
```

</div>

‏`genes` (با s) در هیچ خطی نیست، پس `n` صفر ماند و `s/n` تقسیم بر صفر شد. **اگر پیام «division by zero» دیدید، نخست شرط را وارسی کنید:** به احتمال زیاد غلط تایپی دارد یا جداکننده (`-F`) را فراموش کرده‌اید.

## ۱۱. جمع‌بندی

- ‏`awk` فایل را **خط‌به‌خط** می‌خواند و هر خط را به **ستون‌ها** (`$1`، `$2`…) می‌شکند؛ `$0` کل خط، `NF` شمار ستون‌ها، `NR` شماره‌ی خط است.
- ساختار: `awk -F'\t' 'شرط {کار} END{کار پایانی}' فایل`.
- برای جدول‌های Tab‌دار همیشه `-F'\t'`؛ برای سنجش همیشه `==`؛ برنامه همیشه در `'…'`.
- متغیرها خودشان از صفر شروع می‌شوند: `s+=l` برای جمع، `n++` برای شمار، و `s/n` در `END` برای میانگین.
- ‏`printf` با `%d` (عدد درست) و `%.1f` (یک رقم اعشار) چاپ مرتب می‌کند؛ `\n` را فراموش نکنید.
- در FASTQ، `NR%4==2` خط‌های توالی را برمی‌دارد.

## کارت دستورهای این درس

| می‌خواهم… | دستور |
| :--- | :--- |
| ستون سوم را چاپ کنم | `awk -F'\t' '{print $3}' file` |
| تنها خط‌های ژن | `awk -F'\t' '$3=="gene"' file` |
| آغاز و پایان ژن‌ها | `awk -F'\t' '$3=="gene" {print $4, $5}' file` |
| طول هر ژن | `awk -F'\t' '$3=="gene" {print $5-$4+1}' file` |
| ژن‌های رشته‌ی منفی را بشمارم | `awk -F'\t' '$3=="gene" && $7=="-" {n++} END{print n}' file` |
| میانگین طول ژن‌ها | `awk -F'\t' '$3=="gene" {s+=$5-$4+1; n++} END{print s/n}' file` |
| شمار ستون‌های هر خط | `awk -F'\t' '{print NF}' file` |
| تنها خط سوم | `awk 'NR==3' file` |
| شمار ریدهای FASTQ | `zcat f.fastq.gz \| awk 'END{print NR/4}'` |
| میانگین طول ریدها | `zcat f.fastq.gz \| awk 'NR%4==2 {s+=length($0); n++} END{print s/n}'` |

---

<details>
<summary>📘 <b>برای کنجکاوها (اختیاری):</b> چرا ۱۱۸۷٫۲۵ با <code>%.1f</code> شد ۱۱۸۷٫۲ و نه ۱۱۸۷٫۳؟ و بلندترین ژن را چطور پیدا کنیم؟</summary>

**گرد کردن:** کامپیوتر عددهای اعشاری را در مبنای ۲ نگه می‌دارد و بسیاری از آن‌ها را دقیق نمی‌تواند نگه دارد. افزون بر این، `printf` در حالت «درست وسط» (مانند ۰٫۲۵ ← ۰٫۲ یا ۰٫۳) به سوی رقم **زوج** گرد می‌کند. پس ۱۱۸۷٫۲۵ می‌شود ۱۱۸۷٫۲. برای گزارش علمی این تفاوت‌ها اهمیتی ندارند، ولی اگر دو ابزار در رقم آخر فرق داشتند، دلیلش همین است.

**بیشینه با `if`:** `awk` دستور شرطی `if` هم دارد:

<div dir="ltr">

```bash
awk -F'\t' '$3=="gene" {l=$5-$4+1; if (l>max) max=l} END{print max}' ecoli_k12.gff
```

</div>

<div dir="ltr">

```text
7020
```

</div>

یعنی «اگر طول این ژن از بیشترینِ تاکنون بیشتر است، آن را بیشترین تازه بدان». بلندترین ژن *E. coli* K-12، ژن *yeeJ*، ۷٬۰۲۰ نوکلئوتید است.
</details>

## تمرین‌های کوتاه این درس

> این تمرین‌ها برای سنجش همین درس‌اند؛ پاسخ هر کدام زیرش، تاشده، آمده است. نخست خودتان حل کنید.

**۱.** ستون‌های ۴، ۵ و ۷ (آغاز، پایان، رشته) را برای همه‌ی `CDS`های `small.gff` چاپ کنید.
> **راهنمایی:** بخش ۵، گام ۲. تنها شرط و شماره‌ی ستون‌ها عوض می‌شوند.

**۲.** ژن‌هایی را که بلندتر از ۴٬۵۰۰ نوکلئوتیدند، با آغاز، پایان، رشته و طول چاپ کنید. چندتا هستند؟
> **راهنمایی:** دو شرط با `&&`: نوع ژن، و `$5-$4+1 > 4500`. در بخش «کار»، `print $4, $5, $7, $5-$4+1`.
