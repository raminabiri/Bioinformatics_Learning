# درس: ویرایش متن در لوله با tr و sed

**بخش:** `01_Linux` · **ماژول:** `08_Sed_Tr` · **پیش‌نیاز:** ماژول [awk](../07_awk/) · **زمان:** حدود ۶۰ دقیقه · **ابزار:** tr، rev، sed (GNU) · **آخرین اجرا:** 2026-10-20

---

## در یک نگاه

**در پایان این درس می‌توانید:**
1. با `tr` نویسه‌ها را پاک کنید (`-d`)، تنها برخی را نگه دارید (`-cd`)، یا با نویسه‌ی دیگری جایگزین کنید.
2. یک توالی FASTA چندخطی را به یک خط تبدیل کنید و یک الگو را **درست** در آن بشمارید.
3. درصد GC یک ژنوم را حساب کنید.
4. مکمل معکوس (reverse complement) یک توالی DNA را بسازید (`tr` و `rev`).
5. با `sed` یک تکه از متن را جایگزین کنید (`s/…/…/`)، خط‌هایی را چاپ یا پاک کنید، و دو اشتباه رایجش را بشناسید.

همه‌ی دستورها را در پوشه‌ی `~/Bioinformatics_Learning-main/01_Linux/99_scripts_data/data` اجرا کنید.

---

## ۱. داستان: خطای بی‌صدای ماژول ۰۵

در ماژول ۰۵ دیدیم که `grep` الگوی `GAATTC` (جایگاه برش EcoRI) را در ژنوم «۶۰۳ بار» می‌یابد، ولی این عدد درست نیست: ژنوم در خط‌های ۸۰ حرفی است، و `GAATTC`ای که روی مرز دو خط افتاده دیده نمی‌شود. برای شمردن درست، باید **همه‌ی خط‌های توالی را به هم بچسبانیم** تا کل ژنوم یک رشته‌ی پیوسته شود. این کار یک ابزار ساده می‌خواهد که نویسه‌ی «پایان خط» را پاک کند: **`tr`**.

در همین درس، ابزار ویرایش دیگری هم می‌بینیم: **`sed`**، که یک تکه از متن را با تکه‌ی دیگری جایگزین می‌کند؛ برای نمونه برای کوتاه کردن خط عنوان FASTA یا عوض کردن نام کروموزوم‌ها.

---

## ‏۲. `tr`: کار با تک‌نویسه‌ها

‏`tr` (*translate*) روی **تک‌نویسه‌ها** کار می‌کند، نه واژه‌ها. ورودی را **تنها از لوله** می‌گیرد (نام فایل نمی‌پذیرد). سه کار اصلی:

| شکل | کار | نمونه |
| :--- | :--- | :--- |
| `tr 'abc' 'xyz'` | هر `a` را `x`، هر `b` را `y`، هر `c` را `z` کن | ‏`tr 'acgt' 'ACGT'`: حروف کوچک DNA را بزرگ کن |
| `tr -d 'abc'` | این نویسه‌ها را **پاک** کن | ‏`tr -d '\n'`: پایان‌خط‌ها را پاک کن |
| `tr -cd 'abc'` | **همه چیز جز** این نویسه‌ها را پاک کن (`-c` = *complement*) | ‏`tr -cd 'GC'`: تنها G و C بماند |

‏`'\n'` در `tr` یعنی نویسه‌ی **پایان خط**.

### چسباندن خط‌های FASTA به هم

<div dir="ltr">

```bash
grep -v '^>' ecoli_k12.fna | tr -d '\n' | wc -c
```

</div>

<div dir="ltr">

```text
4641652
```

</div>

#### گام‌به‌گام

| گام | دستور | چه می‌ماند |
| :-: | :--- | :--- |
| ۱ | `grep -v '^>' ecoli_k12.fna` | ۵۸٬۰۲۱ خط توالی (بی خط عنوان) |
| ۲ | `\| tr -d '\n'` | **یک** رشته‌ی پیوسته؛ همه‌ی پایان‌خط‌ها پاک شدند |
| ۳ | `\| wc -c` | شمار نویسه‌ها |

**این خروجی یعنی:** طول ژنوم **۴٬۶۴۱٬۶۵۲ باز** است؛ دقیقاً همان طول NCBI. در ماژول ۰۳ با `wc -c` روی خود فایل ۴٬۶۹۹٬۷۴۵ گرفتیم، چون پایان‌خط‌ها و خط عنوان هم شمرده می‌شدند. حالا هر دو را کنار گذاشتیم. ✓

### شمردن درست EcoRI

<div dir="ltr">

```bash
grep -v '^>' ecoli_k12.fna | grep -o 'GAATTC' | wc -l
grep -v '^>' ecoli_k12.fna | tr -d '\n' | grep -o 'GAATTC' | wc -l
```

</div>

<div dir="ltr">

```text
611
646
```

</div>

- ‏`grep -o … | wc -l` هر **رخداد** را جدا چاپ و سپس شمرد (نه تنها خط‌ها را، برخلاف `-c` که ۶۰۳ می‌داد).
- ولی خط‌به‌خط، **۶۱۱** رخداد پیدا شد؛ پس از چسباندن خط‌ها **۶۴۶**.
- **۳۵ جایگاه EcoRI روی مرز خط‌ها بودند** و بی‌صدا گم شده بودند.

| روش | عدد | چه چیزی را شمرد |
| :--- | ---: | :--- |
| `grep -c 'GAATTC'` | ۶۰۳ | خط‌هایی که دست‌کم یک `GAATTC` دارند |
| ‏`grep -o … \| wc -l` (خط‌به‌خط) | ۶۱۱ | رخدادها، جز آن‌هایی که روی مرز خط‌اند |
| `tr -d '\n' \| grep -o … \| wc -l` | **۶۴۶** | **همه‌ی** رخدادها ✓ |

<summary>✋ <b>امتحان کن:</b> ژنوم چند <code>ATG</code> دارد؟ (هر دو روش را بزنید.)</summary>

<div dir="ltr">

```bash
grep -v '^>' ecoli_k12.fna | grep -o 'ATG' | wc -l
grep -v '^>' ecoli_k12.fna | tr -d '\n' | grep -o 'ATG' | wc -l
```

</div>

پاسخ: `74355` خط‌به‌خط، و **`76282`** پس از چسباندن. روش ساده **۱٬۹۲۷ مورد (۲٫۵٪)** را گم کرد.
</details>

### درصد GC

درصد GC یعنی چند درصد بازها G یا C هستند. با `tr -cd` تنها G و C را نگه می‌داریم و می‌شماریم:

<div dir="ltr">

```bash
grep -v '^>' ecoli_k12.fna | tr -cd 'GC' | wc -c
grep -v '^>' ecoli_k12.fna | tr -cd 'AT' | wc -c
```

</div>

<div dir="ltr">

```text
2357528
2284124
```

</div>

‏`tr -cd 'GC'` یعنی «همه چیز **جز** G و C (حتی پایان‌خط‌ها) را پاک کن». پس ۲٬۳۵۷٬۵۲۸ باز G یا C، و ۲٬۲۸۴٬۱۲۴ باز A یا T. جمعشان دقیقاً ۴٬۶۴۱٬۶۵۲ است، پس این ژنوم هیچ N یا نویسه‌ی دیگری ندارد. درصد را با `awk` (ماژول ۰۷) حساب کنید:

<div dir="ltr">

```bash
echo "2357528 4641652" | awk '{print $1/$2*100}'
```

</div>

<div dir="ltr">

```text
50.7907
```

</div>

‏**GC ژنوم *E. coli* K-12 برابر ۵۰٫۸٪ است**؛ همان عددی که NCBI گزارش می‌کند.

### مکمل معکوس

رشته‌ی دوم DNA **مکمل** (A↔T، C↔G) و **معکوس** (از آن سر خوانده می‌شود) رشته‌ی یکم است. ژن‌های روی رشته‌ی منفی (مانند gyrA) را باید این‌گونه خواند.

<div dir="ltr">

```bash
echo 'ATGGTTTAC' | tr 'ACGT' 'TGCA'
echo 'ATGGTTTAC' | rev
echo 'ATGGTTTAC' | tr 'ACGT' 'TGCA' | rev
```

</div>

<div dir="ltr">

```text
TACCAAATG
CATTTGGTA
GTAAACCAT
```

</div>

| دستور | کار | نتیجه |
| :--- | :--- | :--- |
| `tr 'ACGT' 'TGCA'` | هر A را T، هر C را G، هر G را C، هر T را A کن | مکمل |
| `rev` | ترتیب نویسه‌های هر خط را وارونه کن | معکوس |
| هر دو با هم | — | **مکمل معکوس** ✓ |

‏`echo 'ATGGTTTAC'` یک توالی کوتاه را برای آزمودن در لوله می‌گذارد.

## ‏۳. `sed`: جایگزین کردن متن

‏`sed` (*stream editor*) متن را هنگام گذر از لوله ویرایش می‌کند. پرکاربردترین فرمانش **جایگزینی** است.

### نخستین sed: کوتاه کردن خط عنوان

<div dir="ltr">

```bash
head -n 1 ecoli_k12.fna | sed 's/ Escherichia.*//'
```

</div>

<div dir="ltr">

```text
>NC_000913.3
```

</div>

#### کالبدشکافی فرمان `s/ Escherichia.*//`

<div dir="ltr">

```text
s   /    Escherichia.*    /          /
①   ②          ③          ④    ⑤     ⑥
```

</div>

| بخش | یعنی |
| :-: | :--- |
| ① | ‏`s` = *substitute*: جایگزین کن |
| ② ④ ⑥ | `/` جداکننده‌ی بخش‌هاست |
| ③ | **الگو**: فاصله، سپس `Escherichia`، سپس `.*` (هر چیزی تا پایان خط؛ `.` هر نویسه، `*` صفر یا چند بار) |
| ⑤ | **جایگزین**: این‌جا خالی، یعنی «پاک کن» |

**این خروجی یعنی:** از فاصله‌ی پیش از `Escherichia` تا پایان خط پاک شد و تنها شناسه ماند. چرا؟ بسیاری از ابزارها خط عنوان بلند و دارای فاصله را خوب نمی‌فهمند، و پیش از کار با آن‌ها، کوتاه کردن عنوان‌ها کار رایجی است.

برای کل فایل:

<div dir="ltr">

```bash
sed 's/ Escherichia.*//' ecoli_k12.fna > ecoli_short_header.fna
```

</div>

‏`sed` نام فایل هم می‌پذیرد. خط‌هایی که الگو را ندارند (همه‌ی خط‌های توالی) **بی تغییر** می‌گذرند، پس فایل تازه همان ۵۸٬۰۲۲ خط را دارد.

### یک بار یا همه‌جا: `g`

<div dir="ltr">

```bash
echo 'gene gene gene' | sed 's/gene/GENE/'
echo 'gene gene gene' | sed 's/gene/GENE/g'
```

</div>

<div dir="ltr">

```text
GENE gene gene
GENE GENE GENE
```

</div>

‏`s/…/…/` تنها **نخستین** رخداد هر خط را جایگزین می‌کند. با `g` (*global*) در پایان، **همه‌ی** رخدادها.

### ‏Tab به ویرگول: TSV به CSV

<div dir="ltr">

```bash
head -n 3 ground_truth.tsv | sed 's/\t/,/g'
```

</div>

<div dir="ltr">

```text
sample,read_pairs,accession,organism
minigut,28912,NC_006347.1,Bacteroides fragilis YCH46
minigut,21088,NC_000913.3,Escherichia coli K-12 MG1655
```

</div>

‏`\t` در الگوی `sed` یعنی Tab. هر Tab (با `g`، همه) به ویرگول تبدیل شد. Excel فایل CSV را مستقیم باز می‌کند.

### چاپ و پاک کردن خط‌ها

| فرمان | کار |
| :--- | :--- |
| `sed -n '5,8p' file` | تنها خط‌های ۵ تا ۸ را چاپ کن (همان `head -n 8 \| tail -n 4`) |
| `sed -n '2p' file` | تنها خط ۲ |
| `sed '/^#/d' file` | خط‌هایی را که با `#` آغاز می‌شوند **پاک** کن (همان `grep -v '^#'`) |

‏`-n` یعنی «خودت چیزی چاپ نکن، تنها آنچه `p` می‌گوید». بی `-n`، خط‌های ۵ تا ۸ **دو بار** چاپ می‌شوند.

<details>
<summary>✋ <b>امتحان کن:</b> با <code>sed</code>، نام کروموزوم <code>NC_000913.3</code> را در آغاز هر خط <code>small.gff</code> به <code>chr</code> تبدیل کنید.</summary>

<div dir="ltr">

```bash
sed 's/^NC_000913.3/chr/' small.gff | cut -f1-5 | head -n 3
```

</div>

<div dir="ltr">

```text
chr	RefSeq	region	1	4641652
chr	RefSeq	gene	190	255
chr	RefSeq	CDS	190	255
```

</div>

`^` الگو را به آغاز خط بست، پس `NC_000913.3`های درون ستون ۹ دست نخوردند. (اگر `small.gff` را ندارید، در ماژول ۰۶ ساخته شد.)
</details>

## ۴. اشتباه‌های رایج (با خروجی واقعی)

### اشتباه ۱: `tr` با حروف کوچک

<div dir="ltr">

```bash
echo 'atgc' | tr 'ACGT' 'TGCA'
```

</div>

<div dir="ltr">

```text
atgc
```

</div>

هیچ تغییری نکرد! `tr` بزرگی و کوچکی را جدا می‌داند. در ژنوم‌هایی که بخش‌های تکراری را با حروف کوچک نوشته‌اند (مانند `host_chr21_region.fa`؛ ماژول ۰۳)، مکمل‌سازی با `'ACGT'` نیمی از توالی را دست‌نخورده می‌گذارد. درستش: `tr 'ACGTacgt' 'TGCAtgca'`.

### اشتباه ۲: `/` درون الگوی `sed`

<div dir="ltr">

```bash
echo 'data/raw/a.fastq' | sed 's/data/raw/clean/'
```

</div>

<div dir="ltr">

```text
sed: -e expression #1, char 12: unknown option to `s'
```

</div>

‏`sed` نخستین `/` پس از `data` را پایان الگو گرفت. برای نشانی‌های دارای `/`، **جداکننده‌ی دیگری** بگذارید؛ هر نویسه‌ای پس از `s` جداکننده می‌شود:

<div dir="ltr">

```bash
echo 'data/raw/a.fastq' | sed 's#data/raw#data/clean#'
```

</div>

<div dir="ltr">

```text
data/clean/a.fastq
```

</div>

### اشتباه ۳: `g` را فراموش کردن

<div dir="ltr">

```bash
echo 'NC_000913.3;NC_000913.3' | sed 's/NC_000913.3/chr/'
```

</div>

<div dir="ltr">

```text
chr;NC_000913.3
```

</div>

تنها نخستین رخداد عوض شد. اگر می‌خواهید همه عوض شوند، `g` بگذارید.

## ۵. جمع‌بندی

- ‏`tr` روی تک‌نویسه‌ها کار می‌کند و ورودی را تنها از لوله می‌گیرد: `tr 'abc' 'xyz'` جایگزینی، `-d` پاک کردن، `-cd` نگه داشتن.
- ‏`grep -v '^>' file.fa | tr -d '\n'` کل توالی را یک رشته می‌کند: برای طول درست، شمردن درست الگوها، و درصد GC (`tr -cd 'GC' | wc -c`).
- مکمل معکوس: `tr 'ACGTacgt' 'TGCAtgca' | rev`.
- ‏`sed 's/الگو/جایگزین/'` نخستین رخداد، و با `g` همه‌ی رخدادها را جایگزین می‌کند؛ `sed -n '5,8p'` چاپ خط‌ها؛ `sed '/الگو/d'` پاک کردن خط‌ها.
- اگر الگو `/` دارد، جداکننده‌ی دیگری بگذارید: `s#…#…#`.

## کارت دستورهای این درس

| می‌خواهم… | دستور |
| :--- | :--- |
| کل توالی FASTA در یک خط | `grep -v '^>' f.fa \| tr -d '\n'` |
| طول توالی | `grep -v '^>' f.fa \| tr -d '\n' \| wc -c` |
| شمار درست یک الگو | `grep -v '^>' f.fa \| tr -d '\n' \| grep -o 'GAATTC' \| wc -l` |
| شمار G و C | `grep -v '^>' f.fa \| tr -cd 'GCgc' \| wc -c` |
| حروف کوچک را بزرگ کن | `tr 'acgt' 'ACGT'` |
| مکمل معکوس | `tr 'ACGTacgt' 'TGCAtgca' \| rev` |
| کوتاه کردن عنوان FASTA | `sed 's/ .*//' f.fa` |
| ‏Tab به ویرگول | `sed 's/\t/,/g'` |
| چاپ خط‌های ۵ تا ۸ | `sed -n '5,8p' file` |
| پاک کردن خط‌های توضیح | `sed '/^#/d' file` |
| جایگزینی در نشانی‌ها | `sed 's#data/raw#data/clean#'` |

<details>
<summary>📘 <b>برای کنجکاوها (اختیاری):</b> گروه‌ها در sed، ویرایش در جا، و رشته‌ی دیگر DNA</summary>

**گروه‌ها:** با `sed -E` می‌شود بخشی از الگو را در پرانتز نگه داشت و در جایگزین با `\1` آورد:

<div dir="ltr">

```bash
head -n 1 ecoli_k12.fna | sed -E 's/^>([^ ]+) .*/>\1/'
```

</div>

`[^ ]+` یعنی «یک یا چند نویسه که فاصله نیستند»: همان شناسه. این دستور برای **هر** FASTA کار می‌کند، نه تنها *E. coli*.

**ویرایش در جا (`sed -i`):** `sed -i 's/…/…/' file` خود فایل را بی هیچ نسخه‌ی پشتیبانی تغییر می‌دهد. روی داده‌ی خام **هرگز** این کار را نکنید؛ خروجی را با `>` در فایل تازه بریزید.

**رشته‌ی دیگر:** شمارش‌های این درس تنها روی **یک** رشته‌ی DNA بود. `GAATTC` «پالیندروم» است (مکمل معکوسش خودش است)، پس روی رشته‌ی دیگر هم همان جایگاه‌هاست. ولی `ATG` چنین نیست: برای شمردن ATGهای رشته‌ی دیگر، باید در مکمل معکوس ژنوم هم جستجو کنید.
</details>

## واژه‌نامه‌ی این درس

| اصطلاح | معنی |
| :--- | :--- |
| `tr` | جایگزینی یا پاک کردن تک‌نویسه‌ها |
| `rev` | وارونه کردن ترتیب نویسه‌های هر خط |
| مکمل معکوس (reverse complement) | توالی رشته‌ی دیگر DNA، از آن سر خوانده‌شده |
| درصد GC | درصد بازهای G و C؛ برای هر گونه کمابیش ثابت است |
| `sed` | ویرایشگر جریانی؛ پرکاربردترین فرمانش `s/الگو/جایگزین/` |
| جایگاه برش (restriction site) | توالی کوتاهی که یک آنزیم برش (مانند EcoRI: `GAATTC`) آن را می‌برد |
