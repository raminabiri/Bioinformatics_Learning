## اهداف یادگیری
پس از این ماژول می‌توانید:
1. ساختار یک دستور (نام، گزینه، ورودی) را بشناسید.
2. با pwd، ls و cd میان پوشه‌ها جابه‌جا شوید و نشانی مطلق و نسبی را بشناسید.
3. پوشه بسازید، فایل کپی، جابه‌جا و پاک کنید.
4. پیام‌های خطای رایج را بخوانید.
