۱. آشنایی با Git، GitHub، ابزارهای مشابه و دلیل برتری آن‌ها
Git چیست؟
فرض کنید در حال نوشتن یک پایان‌نامه یا کد برنامه‌نویسی هستید. بارها نسخه‌های مختلفی مثل main.py، main_v2.py یا main_final_FINAL.py می‌سازید تا اگر جایی اشتباه کردید، فایل قبلی را داشته باشید.
Git (گیت) نرم‌افزاری رایگان است که روی کامپیوتر شما نصب می‌شود و تمام این نسخه‌ها را به‌صورت هوشمند مدیریت می‌کند. گیت مانند یک ماشین زمان عمل می‌کند؛ هر بار که نقطه‌ای از کار را ثبت (Commit) می‌کنید، یک «عکس کامل» از وضعیت فایل‌ها می‌گیرد تا هر زمان خواستید بتوانید دقیقاً به همان لحظه بازگردید.
GitHub چیست؟
اگر گیت مثل نرم‌افزار اکسل روی کامپیوتر شما باشد، GitHub (گیت‌هاب) مثل گوگل‌شیت در اینترنت است! گیت‌هاب یک وب‌سایت ابری است. شما پروژه‌هایی را که روی کامپیوتر خود با گیت ثبت کرده‌اید، روی گیت‌هاب آپلود می‌کنید تا:
    1. پشتیبان (Backup) امن داشته باشید.
    2. بتوانید از هر کامپیوتر دیگری به کدهایتان دسترسی پیدا کنید.
    3. با همکاران و پژوهشگران دیگر به‌صورت مشترک روی یک پروژه کار کنید.
    4. نمونه‌کارهای خود را به عنوان رزومه به دنیا نشان دهید.
ابزارهای مشابه گیت‌هاب در وب کدامند؟
علاوه بر گیت‌هاب، سرویس‌های دیگری نیز وجود دارند که دقیقاً بر پایه سیستم گیت کار می‌کنند:
    • GitLab (گیت‌لب): ابزاری بسیار قدرتمند که شرکت‌ها و دانشگاه‌ها می‌توانند آن را روی سرورهای اختصاصی خود نصب کنند تا داده‌های محرمانه از سازمان خارج نشود.
    • Bitbucket (بیت‌باکت): محصول شرکت Atlassian که به‌خوبی با ابزارهای مدیریت پروژه مثل Jira یکپارچه می‌شود و میان تیم‌های تجاری محبوب است.
    • SourceForge (سورس‌فورج): یکی از قدیمی‌ترین پلتفرم‌ها که بیشتر برای دانلود پروژه‌های نرم‌افزاری آزاد استفاده می‌شود.
چرا Git و GitHub از همه بهتر و محبوب‌تر هستند؟
    1. استاندارد طلایی دنیا: گیت توسط لینوس توروالدز (خالق لینوکس) طراحی شد و به دلیل سرعت بالا و مدیریت فوق‌العاده فایل‌ها، جایگزین تمام سیستم‌های قدیمی شد.
    2. جامعه ۱۰۸ میلیونی گیت‌هاب: بزرگ‌ترین اجتماع برنامه‌نویسان و دانشمندان داده در گیت‌هاب حضور دارند. اکثر ابزارهای بیوانفورماتیک، بسته‌های پایتون و مقالات علمی روز، کدهای خود را روی گیت‌هاب منتشر می‌کنند.
    3. رزومه زنده: در دنیای برنامه‌نویسی و بیوانفورماتیک، پروفایل گیت‌هاب شما نشان‌دهنده توانایی واقعی و میزان فعالیت روزانه شماست.
۲. جزوه کامل و گام‌به‌گام جلسه سوم (lesson.md) 

# 📘 جزوه آموزشی: مدیریت پروژه‌ها با Git و GitHub (قدم‌به‌قدم برای مبتدیان)

اگر تا به حال حتی یک خط هم در محیط سیاه ترمینال (Terminal) یا Command Prompt کد نزده‌اید، اصلاً نگران نباشید! این جزوه شما را گام‌به‌گام و از صفر راهنمایی می‌کند.

---

## گام ۱: ساخت یک پوشه روی کامپیوتر و ورود به آن

قبل از اینکه به گیت بپردازیم، باید یک پوشه معمولی برای پروژه‌مان روی کامپیوتر داشته باشیم.

1. روی **Desktop** کامپیوتر خود یک پوشه جدید بسازید و نام آن را `my_project` بگذارید.
2. وارد این پوشه شوید.
3. **باز کردن ترمینال در این پوشه:**
   * **در سیستم‌عامل ویندوز:** در بالای صفحه پوشه، روی نوار آدرس کلیک کنید، عبارت `cmd` را تایپ کرده و کلید Enter را بزنید.
   * **در لینوکس یا مک:** روی فضای خالی پوشه راست‌کلیک کرده و گزینه **Open in Terminal** را بزنید.
   *(همچنین می‌توانید ترمینال را باز کنید و دستور `cd` که مخفف Change Directory است را تایپ کرده، سپس پوشه را کشیده و داخل ترمینال رها کنید).*

---

## گام ۲: تبدیل پوشه معمولی به پوشه گیتی (`git init`)

وقتی ترمینال در پوشه شما باز شد، برای اینکه به گیت بگویم «از این به بعد مواظب فایل‌های این پوشه باش»، دستور زیر را تایپ کرده و Enter بزنید:

```bash
git init

    • توضیح کامل دستور:
        ◦ git: صدا زدن نرم‌افزار گیت.
        ◦ init: مخفف کلمه Initialize به معنی «مقداردهی اولیه» یا «راه‌اندازی».
        ◦ نتیجه: گیت یک پوشه مخفی به نام .git درون پوشه شما می‌سازد و از این لحظه تمام تغییرات را زیر نظر می‌گیرد.
گام ۳: ساخت یک فایل و بررسی وضعیت (git status)
    1. داخل پوشه my_project یک فایل متنی ساده (مثلاً با Notepad) به نام notes.txt بسازید و داخل آن بنویسید: hello bioinformatics.
    2. حالا در ترمینال دستور زیر را بزنید:
git status

    • توضیح کامل دستور:
        ◦ status: به معنی «وضعیت فعلی».
        ◦ نتیجه: گیت نام فایل notes.txt را با رنگ قرمز به شما نشان می‌دهد و می‌گوید این فایل Untracked است؛ یعنی «این فایل جدید است و من هنوز آن را در حافظه‌ام ثبت نکرده‌ام».
گام ۴: گذاشتن فایل در سبد آماده‌سازی (git add)
برای اینکه فایلی را در گیت ثبت کنیم، ابتدا باید آن را وارد «سبد آماده‌سازی» (Staging Area) کنیم.
git add notes.txt
    • توضیح کامل دستور:
        ◦ add: اضافه کردن فایل به مرحله آماده‌سازی.
        ◦ notes.txt: نام فایلی که می‌خواهیم اضافه شود. (اگر به جای نام فایل کلمه . یعنی git add . را بگذارید، تمام فایل‌های جدید پوشه یک‌جا وارد سبد می‌شوند).
اگر دوباره دستور git status را بزنید، نام فایل سبز رنگ می‌شود. این یعنی فایل آماده ثبت نهایی است.
گام ۵: ثبت نهایی عکس از فایل‌ها (git commit)
حالا وقت آن است که تغییرات موجود در سبد را  در تاریخچه گیت ثبت کنیم:
git commit -m "ساخت اولین فایل یادداشت"

گام ۶: متصل کردن پوشه کامپیوتر به وب‌سایت GitHub و آپلود فایل‌ها
حالا می‌خواهیم این پروژه را روی حساب گیت‌هاب خود در اینترنت قرار دهیم.
    1. وارد سایت GitHub.com شوید و یک حساب رایگان بسازید.
    2. در سمت راست بالای صفحه، روی علامت + کلیک کرده و گزینه New repository را بزنید.
    3. یک نام برای مخزن خود بگذارید (مثلاً my_project) و روی دکمه سبز رنگ Create repository کلیک کنید.
    4. گیت‌هاب به شما یک لینک (آدرس) می‌دهد که با .git تمام می‌شود. مانند: https://github.com/your-username/my_project.git
حالا ۳ دستور زیر را به ترتیب در ترمینال کامپیوتر خود اجرا کنید:

# ۱. معرفی آدرس گیت‌هاب به گیت روی کامپیوتر
git remote add origin [https://github.com/your-username/my_project.git](https://github.com/your-username/my_project.git)

# ۲. تغییر نام شاخه اصلی به main (استاندارد جدید)
git branch -M main

# ۳. ارسال (هل دادن) فایل‌ها به گیت‌هاب
git push -u origin main

    • توضیح کلمات دستورات بالا:
        ◦ remote add origin: کلمه remote یعنی «سرور از راه دور»، add یعنی اضافه کن، و origin یک نام مستعار است که گیت برای آدرس اینترنتی شما انتخاب می‌کند.
        ◦ branch -M main: کلمه branch یعنی شاخه، و -M main نام شاخه کدها را به main (اصلی) تغییر می‌دهد.
        ◦ push: به معنی «فشار دادن / فرستادن به بالا». فایل‌های شما را به سرور گیت‌هاب می‌فرستد.
        ◦ -u origin main: پرچم -u (Short for --set-upstream) باعث می‌شود گیت ارتباط کامپیوتر شما و گیت‌هاب را یادش بماند تا دفعات بعدی فقط لازم باشد بنویسید git push.
گام ۷: دانلود پروژه‌های دیگران از گیت‌هاب (git clone)
اگر در گیت‌هاب پروژه یا ابزار بیوانفورماتیکی پیدا کردید و خواستید آن را کامل روی کامپیوتر خود دانلود کنید، کافی است آدرس لینک آن را کپی کرده و دستور زیر را بزنید:
git clone [https://github.com/username/tool-name.git](https://github.com/username/tool-name.git)

    • توضیح کلمه clone: یعنی «همزاد‌سازی / کپی‌برداری دقیق». این دستور یک پوشه جدید روی سیستم شما می‌سازد و تمام کدهای آن پروژه را درونش دانلود می‌کند.
گام ۸: نادیده گرفتن فایل‌های اضافه (.gitignore)
در بیوانفورماتیک فایل‌های داده حجیم (مثل فایلهای چند گیگابایتی FASTQ) وجود دارند که نباید روی گیت‌هاب آپلود شوند.
    1. درون پوشه پروژه یک فایل ساده به نام exact .gitignore (حتما با نقطه شروع شود) بسازید.
    2. پسوند یا نام فایل‌هایی که نمی‌خواهید آپلود شوند را درونش بنویسید:
# نادیده گرفتن تمام فایل‌های زیپ
*.zip

# نادیده گرفتن یک فایل خاص
large_data.fastq
