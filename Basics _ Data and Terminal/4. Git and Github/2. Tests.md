# ✍️ تمرین‌های جلسه Git & GitHub

### ❓ سوال ۱: درک مفهوم کامیت
توضیح دهید دستور `git commit -m "Fix calculation bug"` دقیقاً چه کاری انجام می‌دهد و بخش `-m` چه نقشی دارد؟

---

### ❓ سوال ۲: ترتیب دستورات کار روزانه
فرآیند ۳ مرحله‌ای که هر روز پس از تغییر دادن فایل‌هایتان باید در ترمینال بزنید تا کدهایتان در گیت ذخیره شوند را به ترتیب بنویسید.

---

### ❓ سوال ۳: متصل کردن کامپیوتر به گیت‌هاب
اگر یک مخزن جدید در سایت گیت‌هاب با آدرس `https://github.com/user/dna_analysis.git` ساخته باشید، با چه دستوری این آدرس را به گیت کامپیوتر خود معرفی می‌کنید؟

---

### ❓ سوال ۴: دانلود کد دیگران
برای دانلود کامل پروژه یک محقق دیگر از گیت‌هاب روی کامپیوتر شخصی، از چه دستوری استفاده می‌شود؟

---

### ❓ سوال ۵: مدیریت فایل‌های سنگین
چرا نباید فایل‌های داده‌های توالی‌یابی بسیار سنگین (مثل `.fastq` چند گیگابایتی) را روی گیت‌هاب آپلود کنیم و چطور جلوی گیت را بگیریم تا آن‌ها را شناسایی نکند؟
