# 🔑 پاسخ‌نامه تشریحی تمرین‌های جلسه دوم

---

### 💡 پاسخ سوال ۱
```bash
# ۱. ایجاد پوشه مقصد
mkdir -p ~/miniconda3

# ۲. دانلود اسکریپت نصب
wget [https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh](https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh) -O ~/miniconda3/miniconda.sh

# ۳. اجرای نصب‌کننده در حالت خودکار (-b) و آپدیت (-u)
bash ~/miniconda3/miniconda.sh -b -u -p ~/miniconda3

# ۴. حذف اسکریپت نصب جهت پاک‌سازی
rm -rf ~/miniconda3/miniconda.sh

# ۵. راه‌اندازی اولیه برای پوسته Bash
~/miniconda3/bin/conda init bash

### 💡 پاسخ سوال 2
conda config --add channels defaults
conda config --add channels bioconda
conda config --add channels conda-forge

توضیح: کاندا کانال‌ها را به صورت LIFO (آخرین ورودی، اولین اولویت) تنظیم می‌کند. اجرای دستورات به ترتیب بالا باعث می‌شود اولویت جستجو به این صورت باشد: conda-forge (اول)، bioconda (دوم)، defaults (سوم).

### 💡 پاسخ سوال 3
conda create -y -n seq_qc python=3.9


### 💡 پاسخ سوال4
# فعال‌سازی محیط
conda activate seq_qc

# نصب هم‌زمان دو ابزار
conda install -y fastqc trimmomatic

### 💡 پاسخ سوال 5
conda env list
# یا
conda info --envs
توضیح: در خروجی این دستور، علامت ستاره (*) جلوی هر محیطی باشد، یعنی آن محیط در حال حاضر فعال است.


### 💡 پاسخ سوال6
conda list > installed_packages.txt
توضیح: کاراکتر < خروجی دستور conda list را از ترمینال تغییر مسیر داده و در فایل متنی ذخیره می‌کند.

### 💡 پاسخ سوال 7
conda env export > environment.yml
توضیح: این فایل شامل تمام جزئیات پکیج‌ها، نسخه‌ها و کانال‌های مورد نیاز برای ساخت مجدد این محیط است.


### 💡 پاسخ سوال 8
conda env create -f environment.yml

### 💡 پاسخ سوال 9
# نصب mamba در محیط پایه از کانال conda-forge
conda install -n base -c conda-forge mamba -y

# نصب ابزار samtools با سرعت بالا با استفاده از مامبا
mamba install -y samtools

توضیح: Mamba به زبان ++C نوشته شده و سرعت حل وابستگی‌های سنگین در Bioconda را تا ۱۰ برابر افزایش می‌دهد.

### 💡 پاسخ سوال 10
# ۱. غیرفعال کردن محیط فعلی و بازگشت به base
conda deactivate

# ۲. حذف کامل محیط seq_qc
conda env remove -n seq_qc
