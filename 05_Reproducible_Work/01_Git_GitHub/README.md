## اهداف یادگیری
پس از این ماژول می‌توانید:
1. چرخه‌ی init/add/commit/push را برای یک پروژه‌ی تحلیلی اجرا کنید و با `.gitignore` داده‌ها را بیرون از مخزن نگه دارید.
2. با branch آزمایش کنید، merge کنید و conflict را آگاهانه حل کنید.
3. نسخه‌ی مقاله را با tag علامت بزنید و هر نسخه‌ی قدیمی کد را بازیابی یا اجرا کنید.
4. خطرهای واقعی (رمز یا داده‌ی حساس در تاریخچه) را بشناسید و درست واکنش نشان دهید.
