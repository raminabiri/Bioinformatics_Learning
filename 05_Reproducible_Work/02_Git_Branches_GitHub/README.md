## اهداف یادگیری
پس از این ماژول می‌توانید:
1. با شاخه آزمایش کنید، ادغام کنید و تضاد را آگاهانه حل کنید.
2. نسخه‌ی پایان‌نامه یا مقاله را با tag نشانه‌گذاری کنید.
3. با `--amend` و `revert` اشتباه را درست کنید و بدانید کدام پس از push امن است.
4. با `clone`، `push` و `pull` کار کنید؛ روی GitHub یا یک مخزن ساختگی محلی.
