## اهداف یادگیری
پس از این ماژول می‌توانید:
1. یک مخزن Git بسازید و با `.gitignore` داده‌ها را بیرون نگه دارید.
2. چرخه‌ی `status` ← `add` ← `commit` را اجرا کنید و تغییرها را با `diff` و `log` ببینید.
3. تغییر نادرست را با `restore` دور بریزید و نسخه‌ی کهنه را با `show` ببینید و اجرا کنید.
