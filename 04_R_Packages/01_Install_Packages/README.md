## اهداف یادگیری
پس از این ماژول می‌توانید:
1. یک دستور کوتاه R را با `Rscript -e` از ترمینال اجرا کنید.
2. نصب بودن و نسخه‌ی بسته‌ها را وارسی کنید.
3. بسته‌های CRAN و Bioconductor را از هم بشناسید و با conda یا از درون R نصب کنید.
4. سه خطای رایج نصب را تشخیص دهید و درست کنید.
