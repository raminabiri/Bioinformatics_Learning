## اهداف یادگیری
پس از این ماژول می‌توانید:
1. اسکریپت آماده‌ی R را با ورودی‌هایش اجرا کنید.
2. از روی سرآیند اسکریپت، ورودی‌ها، بسته‌های لازم و خروجی‌ها را بفهمید.
3. پیام‌های `Error`، `Calls:` و `Warning` را بخوانید و علت را پیدا کنید.
4. خروجی و پیام‌ها را جدا ذخیره و نسخه‌ها را ثبت کنید؛ یک تنظیم ساده را در کپی اسکریپت عوض کنید.
